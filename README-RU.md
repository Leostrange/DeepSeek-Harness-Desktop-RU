# DeepSeek Harness Desktop — русская локализация

Эта русскоязычная сборка основана на официальном исходном коде DeepSeek Harness `dsh-v0.2.0-rc.2`. Ветка `desktop-ru/v0.2.0-rc.2` добавляет русский язык в браузерный интерфейс, оболочку Electron и установщик для Windows. После проверки перевода исходники и выпуск будут опубликованы в [DeepSeek-Harness-Desktop-RU](https://github.com/Leostrange/DeepSeek-Harness-Desktop-RU).

Русский язык выбирается в «Настройки → Общие → Язык». Для имеющихся переводов интерфейс переключается сразу; отсутствующие или изменившиеся строки пока показываются по-английски. Переводы описаний плагинов применяются только тогда, когда английское описание пакета совпадает с текстом, для которого сделан перевод. Это предотвращает показ устаревших описаний после обновлений.

Сборка не является официальным выпуском DeepSeek. Windows-установщик, собранный без сертификата подписи, предназначен для самостоятельного тестирования: Windows может показать предупреждение SmartScreen. У сборки отдельный идентификатор приложения и отдельный тестовый канал обновлений; она не должна обращаться к официальному каналу автообновления DeepSeek. Внешняя страница DeepSeek Platform пока получает поддерживаемую ею английскую локаль.

## Сборка для Windows x64

Нужны Node.js 22.19+ или 24+, Corepack/pnpm 11.7.0 и инструменты сборки, перечисленные в [руководстве Desktop](apps/desktop/README.md).

1. Выполните `corepack pnpm install --frozen-lockfile`.
2. Создайте `apps/desktop/.env.windows` на основе [примера](apps/desktop/.env.windows.example). Укажите свой уникальный `DSH_DESKTOP_APP_ID`, HTTPS-адреса тестового канала и `DOWNLOAD_TEST_RELEASE_ID`; не используйте официальный production-канал.
3. Запустите `corepack pnpm --dir apps/desktop exec tsx scripts/package-target.ts win-x64 --unsigned --check`.
4. Запустите `corepack pnpm --dir apps/desktop run package:win:x64:unsigned`.

Неподписанные артефакты появятся в каталоге сборки Desktop. Не публикуйте файлы `.env.windows` и приватные ключи.
