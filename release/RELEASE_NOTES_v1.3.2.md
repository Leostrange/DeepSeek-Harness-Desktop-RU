# DeepSeek Harness Desktop RU v1.3.2

Исправление ошибки метаданных плагинов, появившейся в v1.3.1.

- Карточки служебных плагинов и подпутей больше не показывают `Cannot read properties of undefined (reading 'ru')`.
- Добавлены русские описания установленных плагинов `dsh-ffmpeg`, `dsh-plugin-git-workflow` и `@maxwell-feng/dsh-windows-ocr`.
- Проверен перевод всех 283 встроенных пакетов и добавлен регрессионный тест для карточек без описания.

В релиз входят установщик и portable-дистрибутив. Контрольные суммы находятся в `SHA256SUMS.txt`. Установщик не подписан цифровой подписью.
