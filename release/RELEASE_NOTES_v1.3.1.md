# DeepSeek Harness Desktop RU v1.3.1

Исправлена неполная русификация вкладки «Плагины» в Desktop v1.3.0.

- Добавлены русские описания всех 283 встроенных пакетов DeepSeek Harness `0.1.7-rc.2`.
- Описания подставляются в метаданные плагинов для панели установки и инвентаря настроек.
- Патч автоматически повторяется при запуске Desktop; если английское описание изменится в будущей версии Harness, устаревший перевод не будет применён.

В релиз входят установщик и portable-дистрибутив. Контрольные суммы находятся в `SHA256SUMS.txt`. Установщик не подписан цифровой подписью.
