# DeepSeek Harness Desktop RU v1.3.0

Встроенный официальный DeepSeek Harness обновлён с `0.1.5-alpha.2` до `0.1.7-rc.2` (канал `next`).

Что изменилось в Desktop:

- Русская локализация адаптирована к новому каталогу языков. Добавлены переводы 1 882 новых строк интерфейса в архиве сессий, менеджере плагинов, терминале, настройках, предпросмотре файлов, голосовом вводе и других разделах. Непереведённые строки используют английский fallback.
- Native-клиент открывает одноразовый URL с токеном авторизации, который выдаёт Harness при запуске. Это необходимо для доступа к UI в версии `0.1.7`.
- Обновляторы учитывают новые prerelease-версии npm; исправлена операция замены каталога в плагине обновления.
- Исправление Windows browse-picker применено к новой версии Harness.

Сборка содержит `DeepSeekHarness-Setup.exe` и `DeepSeekHarness-Distribution.zip`. Контрольные суммы указаны в `SHA256SUMS.txt`. Установщик не подписан цифровой подписью.

Официальный upstream: https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.1.7-rc.2
