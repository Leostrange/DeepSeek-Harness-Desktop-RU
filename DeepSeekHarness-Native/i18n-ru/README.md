# Русская локализация DeepSeek Harness

Набор для добавления русского интерфейса в веб-UI DeepSeek Harness.

## Что здесь

- `ru-dicts.json` — полный русский словарь: 31 пространство имён, ~700 строк
  (интерфейс, настройки, модели, плагины, пресеты агентов, права доступа, тема и т.д.).
- `apply-ru.mjs` — скрипт применения патча к установленному пакету `@deepseek-ai/dsh`.

## Как применять

```bash
node apply-ru.mjs          # применить (идемпотентно)
node apply-ru.mjs --revert # откатить всё, что менял скрипт
```

Скрипт делает три вещи:

1. В `@deepseek-ai/dsh-client-locale/lib/client.js`:
   - добавляет `ru` в список локалей (`LOCALES`), поэтому «Русский» появляется
     в Настройки → Язык и подхватывается из языка браузера;
   - внедряет словарь `ru-dicts.json` и регистрирует все пространства имён.
2. Локализует жёстко зашитые названия режимов прав доступа
   («Только чтение» / «Запись в рабочей области» / «Полный доступ»)
   в бандлах `dsh-client-ui-permission-presets` и `dsh-client-ui-conversation`.

Перед первой правкой каждого файла создаётся резервная копия `*.codebuff-ru.bak`.
После применения нужно перезагрузить страницу веб-UI (или перезапустить сервер).

## Путь установки

Скрипт ищет пакет по адресу:

    %APPDATA%\npm\node_modules\@deepseek-ai\dsh\node_modules\@deepseek-ai\

Если пакет `dsh` установлен в другом месте — поправьте `npmRoot` в `apply-ru.mjs`.

## Примечание

Патч меняет файлы внутри глобальной установки npm, поэтому после обновления
`@deepseek-ai/dsh` его нужно применить заново (просто запустите `node apply-ru.mjs`).
